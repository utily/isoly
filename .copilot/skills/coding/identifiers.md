Identifiers

Language: TypeScript

Rules:
- Prefer single-word identifier names (e.g., `user`, `count`, `format`).
- Two-word identifiers are acceptable when they increase clarity (e.g., `startDate`, `userId`).
- Avoid abbreviations except: `UI`, `Id`, `max`, `min`.
- Single-letter identifiers are allowed only for very local, short-lived usage (maximum 3 lines of usage).
- Prefer descriptive names for exported symbols; prefer clarity over brevity when crossing module boundaries.

Rationale:
These rules balance succinctness with readability and align with the repository's existing conventions.
